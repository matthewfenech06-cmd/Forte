Download the app icon in every size you need for App Store submission and iOS home screen.

Previews + Downloads

How to use

Step 1
Download 1024x1024
This is your App Store icon. Save it as forte-icon-1024.png. No alpha channel required (it has a solid background already).
Step 2
Download 180x180 (iPhone)
Rename it forte-apple-icon.png and drop it in your Forte project folder. This is the home screen icon for iOS Safari.
Step 3
App Store Connect
In App Store Connect, upload the 1024x1024 PNG to App Information. Xcode / PWABuilder will handle the other sizes automatically from this source.
Step 4
Add to project
After saving forte-apple-icon.png to the Forte folder, commit it:
git add forte-apple-icon.png && git commit -m "add apple touch icon" && git push origin main
